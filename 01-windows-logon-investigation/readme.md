# Windows Logon Activity Investigation

A controlled laboratory investigation of Windows authentication activity using Security Event IDs 4624 and 4625.

## Objective

To analyze successful and failed authentication events and reconstruct a basic authentication timeline.

## Environment

- Windows VM
- VMware Workstation
- Windows Event Viewer
- Windows Security Log

## Events Investigated

- Event ID 4624 — Successful Logon
- Event ID 4625 — Failed Logon

## Investigation

The investigation analyzes the relevant event fields, compares failed and successful authentication attempts, and reconstructs the activity timeline.
