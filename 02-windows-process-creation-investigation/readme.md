# Windows Process Creation Investigation

## Investigating Windows Process Creation Using Event ID 4688

This investigation examines **Windows Security Event ID 4688 — "A new process has been created"** to understand how process creation activity is logged and how it can be used to reconstruct user and system behavior on a Windows endpoint.

The investigation was conducted in a controlled Windows 10 Virtual Machine environment using Windows Event Viewer and the Windows Security Log.

---

## Objective

The investigation aims to:

- Understand what Event ID 4688 records at the process, user, and session level
- Identify the creator/parent process and newly created child process
- Analyze command-line arguments associated with process execution where auditing permits
- Examine process creation activity in relation to session information
- Investigate the relationship between Event ID 4688 and Event ID 4624
- Use process creation events to reconstruct user and process activity

---

## Investigation Question

> What can Windows Event ID 4688 reveal about processes executed on a Windows endpoint, and how can an analyst use process creation events to reconstruct user and process activity?

## Event ID 4688

Event ID 4688 is generated by the Windows Security Auditing subsystem whenever a new process is created.

The event provides timestamped information about process execution and can include:

- Subject / account information
- Subject Logon ID
- New Process Name
- New Process ID (PID)
- Creator Process Name
- Creator Process ID
- Process Command Line
- Token Elevation Type

Event ID 4688 can therefore be used to examine process execution and reconstruct parent-child process relationships.

Process Creation auditing was enabled to generate Event ID 4688 events.

The investigation also enabled command-line auditing so that command-line information could be captured with process creation events.
